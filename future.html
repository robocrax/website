Open Source Project

Google Photos Free Uploader

Continuous backup daemon preserving Google Photos unlimited quota tiers.

View on GitHub ↗️

gpmc-daemon monitors local file directories and streams photos/videos to Google Photos using OEM compression profiles, allowing storage saving without burning Google Drive storage tiers.

git clone https://github.com/robocrax/gpmc-daemon.git
cd gpmc-daemon && make build
./gpmc-daemon --watch /path/to/photos
Open Source Project

Heartbeats Ping Sidecar

Container monitoring daemon with conditional HTTP pings.

View on GitHub ↗️

A zero-overhead Go binary designed to run alongside docker clusters. It periodically pings local or remote endpoints (ICMP/TCP) and triggers an external heartbeat (such as Healthchecks.io) strictly when all checks pass.

docker run -d \
  -e TARGET_IP="192.168.1.50" \
  -e HEARTBEAT_URL="https://hc-ping.com/YOUR-UUID" \
  ghcr.io/robocrax/heartbeats-ping-sidecar:latest
